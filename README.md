# 🏆 Trybets  

## ✨ Descrição Breve  
Um projeto que consistiu na migração de uma aplicação monolítica para diversos microsserviços, separando as rotas de interesses específicos em aplicações independentes. Também foi desenvolvido o setup de **Dockerfiles** para cada microsserviço, visando criar imagens e containers separados, além de configurar um **Docker Compose** para a aplicação completa.

## 🚀 Como Rodar o Projeto  
1. Clone o repositório:  
   ```bash
   git clone https://github.com/Gzuuu/trybets.git
   ```  
2. Acesse a pasta do projeto:  
   ```bash
   cd trybets/src
   ```  
3. Instale as dependências:  
   ```bash
   dotnet restore

## 🛠️ Tecnologias Utilizadas  
- **C#**  
- **.NET**  
- **Docker**  
- **Docker Compose**  

## ⚙️ Funcionalidades  
- 🛠️ Migrar uma aplicação monolítica para **microsserviços**.  
- 📁 Separar rotas de interesse em aplicações independentes.  
- 🐋 Criar **Dockerfiles** para cada microsserviço.  
- ⚙️ Configurar **Docker Compose** para rodar a aplicação completa.  

## 📚 Principais Aprendizados  
- Compreensão da arquitetura de **microsserviços**.  
- Habilidade de interpretar e adaptar código fonte pré-existente.  
- Separação de responsabilidades de uma aplicação monolítica.  
- Preparação de **imagens Docker** para aplicações web.
